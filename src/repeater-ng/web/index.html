💡 Radio Allocation Architecture

• 5GHz Radio (wl1): Dedicated solely to local AP broadcast for smartphones, laptops, and devices with high-speed AC performance.

• 2.4GHz Radio (wl0): Dedicated solely to the Upstream Repeater client. Keeping 2.4GHz local AP disabled avoids radio loopback and guarantees an uninterrupted upstream connection.

💡 Hardware RGB LED States & Boot Sequence

JCOW411 front LED indicator states managed by /pfrm2.0/bin/set_led.sh

Driver: /bin/ledctl1
Normal Boot Sequence Timeline (~60-90s)
Solid Red (Boot) → Blinking Blue (Scan) → Solid Blue (Handshake) → Blinking Green (DHCP) → Solid Green (Online & NAT Active)
1. Boot / Init
Solid Red

Router booting or unconfigured station mode.

2. Scanning
Blinking Blue

Triggering spectrum scan for upstream Wi-Fi target.

3. Associating
Solid Blue

wpa_supplicant performing 4-way WPA2 key handshake.

4. Obtaining IP
Blinking Green

Association completed; udhcpc requesting DHCP lease.

5. Online
Solid Green

Gateway reachable, iptables NAT applied, full internet.

6. Dropped
Solid Yellow (R+G)

Upstream link temporarily lost or gateway ping failed.

7. Retrying
Blinking Yellow

Re-scanning airwaves; attempting failover saved profile.

8. Fatal
Fast Blinking Red

All 4 retry attempts exhausted. Manual Telnet check needed.

🛠️ Emergency & Diagnostic Terminal Commands

Execute via Telnet (192.168.29.1 port 23) for real-time investigation and recovery

Click to Copy
1. Live 4-Way Handshake & Deauth Trace

Monitors wpa_supplicant state changes, EAPOL frames, and Reason codes in real-time.

tail -f /tmp/wpa.log | grep -E 'State:|DEAUTH|DISCONNECT|reason|4-Way|COMPLETED'
2. Broadcom Radio & Association Counters

Checks wl0 station link, wl1 5GHz AP status, and lists all connected mobile MACs.

wl -i wl0 status && wl -i wl1 status && wl -i wl1 assoclist
3. Emergency Repeater Re-Trigger (No Reboot)

Forces a clean station teardown, re-runs dynamic spectrum scan, and re-connects.

/bin/sh /pfrm2.0/bin/repeater_engine.sh
4. 5GHz Hostapd & EAPD Resync

Restarts both eapd and hostapd together if phones report authentication errors.

killall -9 hostapd eapd 2>/dev/null; sleep 1; eapd &; sleep 1; hostapd -B /tmp/wl1_hapd.conf
5. Engine Execution Log (Last 30 Events)

Dumps boot-time and retry activity logs with timestamps and IP assignments.

cat /tmp/repeater_engine.log | tail -n 30
6. Active Clients & ARP Subnet Table

Queries active kernel ARP entries and DHCP leases currently attached to bdg2.

cat /proc/net/arp | grep bdg2 && cat /var/dhcpd.leases 2>/dev/null
7. Verify Routing & NAT IP Forwarding

Confirms default gateway route on wl0 and active MASQUERADE / DNS NAT rules.

route -n && iptables -t nat -L POSTROUTING -n -v
8. Synchronize Clock via Internet NTP

Manually contacts Google NTP servers and sets real-world date and time.

/pfrm2.0/bin/ntpclient -s -h time.google.com 2>/dev/null || ntpd -q -p time.google.com 2>/dev/null; date
