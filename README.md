# JF-ROUTER-W411

Research tools and router-side scripts for Jio Fiber ONT devices. Changes can
remove ISP features or brick hardware; start with [safety and recovery](docs/reference/safety-and-recovery.md).

## Verified in this fork

- JCOW411 R2.3 root-access/config work.
- JCOW411 routed Wi-Fi repeater workflow; see the [guide](docs/instructions/wifi-repeater-jcow411.md) and [timeline](TIMELINE.md).

All other model and firmware claims are legacy or experimental until verified.

## Documentation

See the [documentation index](docs/README.md). Put decrypted backups, keys,
real router scripts, and credentials only in ignored `artifacts/`.
